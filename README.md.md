## 🍽️ About

**Khana Khajana** is a modern, single-page restaurant website built for a premium family garden restaurant in **Jhunjhunu, Rajasthan**. The goal was simple: give every visitor an appetizing first impression the moment the page loads, and make it effortless for them to go from *"this looks nice"* to *"table booked"* — all without leaving a single page.

It's built to feel warm and inviting like the restaurant itself — a blend of indoor dining elegance and open garden charm — while staying fast and lightweight enough to load instantly on a visitor's mobile data.

## ✨ Features, Explained

### 🖼️ Hero Collage & Full Gallery
The homepage opens with a curated photo collage that instantly sets the mood — food, ambience, and garden views in one glance. A dedicated full-gallery collage lets visitors browse a wider set of restaurant photography without needing a separate gallery page or slow image carousel.

### 🎥 Video Showcases
Two embedded videos — a **garden tour** and a **restaurant reel** — give visitors a real feel for the space before they arrive. Video does a better job than photos alone at conveying atmosphere, especially for the garden seating area.

### 🍛 Menu Showcase
Rather than a plain text menu, dishes are presented as rich visual cards — thalis, curries, paneer specialties, naan combos, and more — so visitors can literally see what they're ordering. Desserts and drinks (lassi, jalebi, rasmalai, cold coffee) get their own spotlight too.

### 🌳 Garden & Venue Tour
Separate visuals for the **indoor dining hall**, **main hall**, and **outdoor garden walkway/entrance** help visitors picture exactly where they'll be seated — useful for anyone choosing between an indoor or garden-side table.

### 📍 Map Integration
An embedded map makes the restaurant easy to find with a single tap, removing the friction of copy-pasting an address into a separate maps app.

### 💬 Direct WhatsApp Contact
A one-tap **WhatsApp button** lets visitors message the restaurant directly for reservations or questions — no phone calls, no contact forms, just an instant chat, which is how most people in the region already prefer to communicate with local businesses.

### ⭐ Customer Reviews
Real review highlights are displayed directly on the page as social proof, helping build trust with first-time visitors before they've even stepped inside.

### 📱 Fully Responsive Design
Every section — hero, gallery, menu, videos, map, and reviews — adapts cleanly across mobile, tablet, and desktop, since most visitors will be discovering the restaurant from their phone.

### ⚡ Lightweight & Fast
No frameworks, no build step, no bloated libraries — just clean HTML, CSS, and JavaScript. This keeps load times fast even on slower mobile networks, which matters for a location-based business where visitors are often checking the site on the go.

## 🚀 Getting Started

This is a fully static site — no build step, no dependencies to install.

```bash
git clone https://github.com/harshrolan2009-droid/khana-khajana.git
cd khana-khajana
```

Then simply open `index.html` in your browser to view it locally.

## 🌍 Deployment

### Deploy to Netlify (recommended)
1. **Drag & drop** — go to [Netlify Drop](https://app.netlify.com/drop) and drag the project folder in for an instant live URL, **or**
2. **Git-connected deploy** — connect this repository to Netlify for automatic deploys on every push, no configuration needed.

### Other static hosts
Since there's no build step, this project deploys just as easily to **Vercel**, **GitHub Pages**, **Cloudflare Pages**, or any static file host — just upload the folder as-is.
